# Amazon Prime Video Analysis Dashboard

## Project Overview
This Power BI project analyzes Amazon Prime Video content, including Movies and TV Shows.

## Objectives
- Analyze content distribution by type
- Explore ratings and genres
- Identify trends in release years
- Compare Movies vs TV Shows
- Visualize content availability

## Tools Used
- Power BI
- Excel/CSV
- Data Cleaning
- Data Visualization

## Key Insights
- Total number of Movies and TV Shows
- Most common genres
- Content distribution by rating
- Release year trends
- Country-wise content analysis
